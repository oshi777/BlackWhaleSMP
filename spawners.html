SmartSpawners Guide
Learn everything you need to know about SmartSpawners and how to use them effectively
How It Works
  • Place the spawner down
  • Stay within 16 blocks to keep it active
  • Every 22 seconds it generates drops automatically
  • Auto-collect drops into internal storage
  • Right-click to open the GUI
Tip: No killing mobs or AFK grinders needed — it's fully automatic!
Storage System
  • Capacity: 45 item slots (1 storage page)
  • Collect items directly from GUI
  • Sell directly from GUI (no item removal needed)
  • Claim XP anytime from storage
Note: If storage is full, the spawner pauses until you empty it. Items can be taken out or sold without breaking the spawner.
Stacking Spawners
  • Same type spawners can be stacked together
  • Max stack size: 10,000 spawners
  • More stacked = more drops per cycle
  • Stack method: Right-click one spawner with another of the same type in hand
Spawn Rate: 1-5 mobs per cycle per spawner. Higher stacks multiply this output!
Breaking & Collecting
  • Requires: Silk Touch pickaxe
  • Allowed tools: Iron, Golden, Diamond, or Netherite Pickaxe with Silk Touch
  • Breaking without Silk Touch = You lose vanilla spawners
  • SmartSpawners won't break without Silk Touch
  • Dungeon spawners can also be collected the same way
Selling Items
  • Method 1: Use the Sell button in spawner GUI
  • Method 2: Take items out and sell via /shop manually
  • Prices are pulled from the server shop (EconomyShopGUI-Premium)
  • Convenience: Sell directly without managing inventory
XP Management
  • Accumulates XP over time internally
  • Max stored XP: 50,000 points
  • Claim anytime from the GUI to level up
  • Use for Mending: Repair items directly from GUI using stored XP
Bonus: XP repair works with Mending items right from the spawner interface!
Spawn Rate
  • Per Spawner: 1-5 mobs per cycle
  • Cycle Duration: Every 22 seconds
  • Average: 3 mobs per 22 seconds
  • Variation: Exact rate depends on mob type and drop rates
